# Language Translation Tool

An AI-powered language translation tool built using Python, Streamlit, and Google Gemini API.

## Live Demo

https://polyglot-translator.streamlit.app/

## Screenshot

![Language Translation Tool](screenshots/language-translator.png)

## Features

- Translate text between 80+ languages
- Searchable language selection
- Romanized translation
- Native script translation
- Translation history
- Natural and casual translations
- Google Gemini AI integration
- Simple and user-friendly interface
- Deployed using Streamlit Community Cloud

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- python-dotenv
- Git
- GitHub

## How It Works

1. Select the source language.
2. Select the target language.
3. Enter the text to translate.
4. Click the **Translate** button.
5. The application generates both Romanized and Native Script translations.
6. Previous translations are displayed in the Translation History section.
